## 工作流程

工作流包含三个步骤，**每步执行完成后必须等待用户确认**才能继续下一步：

### 步骤1：数据识别
**触发条件**：用户提供了初始数据

**操作**：
1. 询问用户初始数据

**用户确认点**：
- 向用户展示具体的数据
- 询问："步骤1完成：请检查数据是否正确，确认后继续下一步？"
- 等待用户明确回复（如"确认"、"继续"、"下一步"等）

### 步骤2：初始数据预处理
**触发条件**：用户确认步骤1完成且数据正确

**操作**：
1. 将输入的数据乘10
2. 输出计算结果

**用户确认点**：
- 向用户展示计算结果
- 询问："步骤2完成：请检查计算是否正确，确认后继续下一步？"
- 等待用户明确回复

### 步骤3：格式化数据
**触发条件**：用户确认步骤2完成且数据正确

**操作**：
1. 输出 `Total B_last sum: XXX.XX` 格式的最后数据

**用户确认点**：
- 告知："步骤3完成：房租结算单已生成，本月共收租 XXX 元。工作流全部完成！"

## 错误处理

### 如果某个步骤失败：
1. 记录错误信息
2. 向用户说明失败原因
3. 询问是否重试或跳过该步骤
4. 不要自动继续到下一步

### 如果用户要求修改：
1. 允许用户回退到上一步
2. 重新执行该步骤
3. 再次等待确认

## 使用示例

**示例1 - 完整工作流：**
用户："开始计算流程"
→ 询问初始数据
→ 执行步骤1 → 等待确认
→ 执行步骤2 → 等待确认
→ 执行步骤3 → 完成

## 注意事项

- **必须**每步完成后等待用户确认，不要自动连续执行
- 如果用户在中途退出，下次可以从任意步骤恢复
- 用户可以在任何步骤要求修改输入或重新执行

### 收尾工作
操作全部完成后，**必须**调用 `workflow_complete` tool 标记本次收租工作流已结束：
```
workflow_complete
```
不要省略这一步，否则系统无法判断工作流何时真正完成。
